# mod-tier0-trainers

Remaps classic-continent profession trainers so Tier 0 / level-60 progression can train professions to 300 without relying on TBC/WotLK-only trainer lists.

Designed to work alongside Individual Progression Tier 0.

## Install

```bash
cd modules
git submodule add https://github.com/VenomekPL/mod-tier0-trainers.git mod-tier0-trainers
```
